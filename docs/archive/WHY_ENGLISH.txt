FANTASTIC CREATURES PLUS
========================

The mod database uses English ASCII names and text for compatibility with the
game data. Creature origins are included in each creature description.

The mod includes:
- Eight custom creature races and portraits
- Ten abilities and twelve traits
- Eight named, themed weapons with fixed item skills
- Eight encounter sets with biome-specific terrain
- Sixteen story events with Fight, Tame, Recruit, and Flee choices

Weapons use hidden item recipes, custom item tags, guaranteed skill packs, and
one-item cargo profiles. Adult creatures recruited through encounters receive
their default cargo, including their named weapon.

Traits are implemented as innate skills using supported game effects. The base
database has no direct fire immunity or underwater breathing effect, so those
two names use generic shielding bonuses. Petrifying Gaze uses the built-in
enemy delay effect.

The active mod files are listed in info.txt. Database files are in DB/, and
creature portraits are in Images/Portraits/. No extra text file is placed in
the mod root.

Close Thea 2 before testing updated files; Steam can remain open. The XML and
reference checks do not replace an in-game load test.
